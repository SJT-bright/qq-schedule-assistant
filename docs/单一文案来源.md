# 单一文案来源（v3.8.0）

在“新建发送 → 文案与配图”选择文案，在唯一的正文框修改，点击“保存并同步”。同一文案来源的所有待执行、可重试且未提交任务同步新正文，之后加入计划的群也使用新正文。正在处理、草稿待确认、已提交、结果待核对和已发送记录保留当时正文。不同空间、不同文案来源互不影响。

编辑时自动保留草稿，点击保存或创建计划才提交到文案来源。文案区点击标题即可收起；下拉框切换文案，更多菜单提供另存和删除。新建计划保存来源 ID，后续修改仍然关联这一条。

旧计划在所属空间内按唯一同文内容关联；仅有一条文案的空间关联这一条。无法唯一关联的多文案旧计划保留快照。删除文案后，相关计划保留最后保存的正文。

发送队列点击“间隔设置”在按钮下方展开分钟输入、快捷值、应用间隔及全局间隔说明；再次点击即可收起。统计信息与每条任务的操作横向排列。
